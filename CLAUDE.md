# «Обратно» — правила репозитория

Продукт ИИ-Хакатона Tutu поверх публичного `https://mcp.tutu.ru/mcp`.
Задание и критерии — в [`docs/brief/`](docs/brief/), ТЗ продукта — в
[`docs/brief/obratno.md`](docs/brief/obratno.md).

## Железные правила

1. **Только `uv`** для Python: `uv sync`, `uv add`, `uv run`. Никогда `pip`, `venv`, `poetry`.
   Фронт — только `pnpm`.
2. **Только последние версии библиотек**, сверенные по реестрам (PyPI, npm) или Context7 в день
   добавления, а не по памяти. Версии прибиты точно, лок-файлы коммитятся.
3. **Ничего не выдумывать за Tutu.** В интерфейс попадает только то, что пришло в ответе. Пустое
   поле подписывается «Tutu не вернул это поле», а не заполняется догадкой. `checkout_url`
   выводится ровно как пришёл, без перестройки.
4. **Любая оценка помечена как оценка.** Рядом с числом, которого нет в ответе MCP (расстояние,
   цена такси, время пешком), стоит подпись, откуда оно взялось.
5. **Время только tz-aware.** Сравнение по времени суток запрещено: `01:22` следующих суток
   приходит в ответе на сегодняшнюю дату. Внутри домена — минуты от местной полуночи даты запроса.
6. **Комментарии и docstring — RU и EN** на публичных интерфейсах. Русский первым.
7. **Тесты на всё, что считает.** Доменная математика и парсеры ответов MCP покрываются тестами
   до реализации. Порог покрытия домена — 80%.
8. **Никакого AI-слопа в интерфейсе.** Список запретов — в
   [`docs/design/DESIGN.md`](docs/design/DESIGN.md), он блокирующий.
9. **Архитектурное решение — сначала ADR, потом код.** `docs/adr/NNNN-*.md`.
10. **Conventional Commits.** Ассистент не упоминается ни в авторстве, ни в теле коммита.

## Границы

| Артефакт | Норма | Максимум |
|---|---|---|
| Функция | < 30 строк | 50 |
| Файл | 200–400 строк | 800 |
| Вложенность | ≤ 3 | 4 |

## Слои бэкенда

```
api  →  application  →  domain
             ↓
      infrastructure
```

`domain` не импортирует ни FastAPI, ни httpx — только стандартную библиотеку. Нарушение
направления зависимостей — блокирующее замечание.

## Команды

```
make dev        бэкенд и фронт в режиме разработки
make warm       прогреть кэш веера на сегодня и завтра
make test       тесты бэкенда и фронта
make lint       ruff, mypy, eslint, tsc
```
