## Задание дословно

> Тут без изменений — любой продукт на базе нашего MCP: **https://mcp.tutu.ru/mcp**
> Документация — по этой же ссылке.
>
> **От себя рекомендация:** не ограничивайте полёт фантазии, **голосовые помощники утомляют**.
> Проведите исследование, проанализируйте, что действительно могло бы встряхнуть рынок тревела.

Четыре рамки на слайде: свежий взгляд на сервис путешествий · что действительно было бы удобно
клиенту · **интерфейсное решение** · упор на необычность решения, не бойтесь экспериментов.

## Критерии оценки

| Глубина проработки функционала | 15 |
| **Качество UX/UI** | **20** |
| Презентация | 5 |
| Проработка документации — AI-проверка | 10 |
| Инновационность технологий | 10 |
| Стабильность работы | 10 |

| Техническая часть — 20 | Баллы |
|---|---:|
| Архитектура приложения — AI-проверка | 10 |

## Как это задание прочитано в продукте

| Строка рубрики | Где отвечено |
|---|---|
| Интерфейсное решение, необычность | Поля «куда» не существует. Ввод — один циферблат, ответ — география |
| Голосовые помощники утомляют | Голос ужат до одного факта в [`../adr/0007-alice-skill.md`](../adr/0007-alice-skill.md), это не главный экран |
| Глубина проработки | Переход через полночь, потолок пагинации, обрезанное окно ответа — [`../mcp/probe-log.md`](../mcp/probe-log.md) |
| Стабильность | Тёплый кэш, ретраи, деградация до записанных ответов — [`../adr/0004-caching-and-degradation.md`](../adr/0004-caching-and-degradation.md) |
| Качество UX/UI | [`../design/DESIGN.md`](../design/DESIGN.md) |
| Архитектура и код — AI-проверка | [`../adr/`](../adr/), слои в `backend/src/obratno/` |
