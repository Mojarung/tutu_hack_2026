# ADR 0005 — Математика часов на земле считается на клиенте

**Статус:** принято, 2026-08-19

## Контекст

Главный жест продукта — перетаскивание циферблата. Оно обязано идти в 60 FPS. API, отвечающий
за секунды, в этот бюджет не помещается ни при каких оптимизациях: даже 50 мс на запрос дают
рывки на каждом кадре.

## Решение

Бэкенд отдаёт **расписание**, клиент считает **ответ**.

Единица обмена — `StationField`: для каждой станции два отсортированных списка рейсов,
в минутах от местной полуночи запрошенной даты.

```jsonc
{
  "code": "sergiev-posad", "name": "Сергиев Посад", "lat": 56.3086, "lon": 38.136,
  "out":  [[280, 375], [310, 402]],        // [отправление из дома, прибытие туда]
  "back": [[239, 331], [1372, 1463]],      // [отправление оттуда, прибытие домой]
  "out_truncated": false, "back_truncated": false,
  "out_total": 56, "back_total": 56
}
```

Минуты монотонны и **не заворачиваются на полуночи**: отправление 01:22 следующих суток — это
`1522`. Это тот самый выбор представления, который делает ошибку красной команды невозможной
структурно, а не по договорённости.

Решение для дедлайна `D` и минимума часов на земле `G`:

1. взять самый поздний рейс из `back`, у которого прибытие домой `≤ D`;
2. взять рейс из `out` с самым ранним прибытием, которое `≤` его отправления;
3. часы на земле = отправление обратно − прибытие туда; станция светится, если это `≥ G`.

36 станций × до 300 рейсов — это доли миллисекунды на кадр.

## Дублирование логики и как оно удержано

Та же математика нужна серверу — для карточки обрыва и для навыка Алисы. Одна функция живёт в
двух языках, и это осознанный размен: производительность жеста против единственной реализации.

Расхождение ловится тестом, а не дисциплиной. `backend/tests/test_ground_time.py` порождает
`web/src/domain/__fixtures__/ground-time.json`: набор входов и эталонных ответов, посчитанных
Python-реализацией. `web/src/domain/field.test.ts` прогоняет по нему TypeScript-реализацию.
Разошлись — красный тест на обеих сторонах.

## Последствия

- Перетаскивание циферблата не делает ни одного сетевого вызова, как и требует ТЗ.
- Счётчик «сколько станций доступно» пересчитывается на каждом кадре без дрожания.
- Любое изменение правил (пересадочный запас, «выехать не раньше») меняется в двух местах,
  и тест на фикстуре об этом сразу сообщит.
