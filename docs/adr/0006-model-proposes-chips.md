# ADR 0006 — Модель предлагает чипы, применяет их человек

**Статус:** принято, 2026-08-19

## Контекст

Хакатон — ИИ-хакатон, и у продукта должна быть внятная роль модели. При этом продукт про числа:
последняя электричка, минута на платформе, часы на земле. Модель, которая произносит такие
числа, рано или поздно произнесёт неверное.

## Решение

У модели ровно одна работа: **разобрать свободный текст в набор видимых редактируемых чипов**.

```
«хочу погулять полдня, вернуться до полуночи, без пересадок»
    ↓
[ дома к 00:00 ]  [ хотя бы 6 ч там ]  [ только прямые ]
```

Жёсткие ограничения:

1. **Модель не касается расписаний.** Она видит только текст пользователя и словарь известных
   станций. Ни один оффер, ни одно время из ответа Tutu в неё не попадает.
2. **Выход строго типизирован** и валидируется схемой: дедлайн, минимум часов, дата, станция,
   только прямые. Всё, что не разобралось, отбрасывается.
3. **Ни один чип не применяется молча.** Чипы появляются в интерфейсе как предложение, их можно
   отредактировать или выкинуть, и только нажатие «применить» двигает циферблат.
4. **Продукт полностью работает без модели.** Без ключа тот же текст разбирает детерминированный
   парсер на регулярных выражениях, и он же — фолбэк при таймауте. Источник разбора подписан в
   интерфейсе: «разобрано моделью» или «разобрано локально».

## Провайдер

OpenAI-совместимый эндпоинт, задаётся конфигом: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`.
По умолчанию — `https://ollama.com/v1`. Ключа в репозитории нет; без него включается
детерминированный путь, а не заглушка с ошибкой.

## Последствия

- Модель структурно не может соврать числом: она не видит чисел, которые могла бы исказить.
- Единственная дыра, на которую судья может показать пальцем на ИИ-хакатоне, закрыта видимым
  и осмысленным применением модели.
- Демо не зависит от доступности LLM.
